# McDonald's Menu Website 🍔

A beautiful, interactive McDonald's menu website built with HTML, CSS, and JavaScript.

## Features ✨

- **19 Menu Items** across 5 categories:
  - 🍔 Burgers (Big Mac, Quarter Pounder, McDouble, etc.)
  - 🍗 Chicken (Crispy/Grilled Sandwiches, Nuggets)
  - 🍟 Sides (Fries, Salad, Apple Slices, Corn)
  - 🥤 Drinks (Coca-Cola, Coffee, Orange Juice, Tea)
  - 🍦 Desserts (Apple Pie, Shakes, Ice Cream)

- **Interactive Filtering** - Click category buttons to filter menu items
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Smooth Animations** - Hover effects and fade-in animations
- **McDonald's Branding** - Official red & yellow color scheme

## How to Use 🚀

1. Open `index.html` in your web browser
2. Click category buttons (Burgers, Chicken, Sides, Drinks, Desserts) to filter items
3. Hover over menu items to see animations
4. Click "Add to Order" to add items to your order

## Files 📁

- **index.html** - Main HTML structure
- **styles.css** - Responsive styling and animations
- **script.js** - Interactive JavaScript functionality
- **README.md** - This file

## Technologies Used 💻

- HTML5
- CSS3 (with Grid, Flexbox, animations)
